# marketplace-pwa Project Context

## What This Is
Closed marketplace PWA — React frontend + NestJS backend with CometChat, payments, referral system.

## Architecture
- `frontend/` — React 19, TypeScript 6, Vite 8, TailwindCSS 4, PWA
- `backend/` — NestJS 11, Prisma, PostgreSQL, Redis, JWT auth
- Docker Compose — PostgreSQL 16 + Redis 7

## Key Files
- `frontend/src/App.tsx` — routes, 25 pages
- `frontend/src/components/` — 11 UI components
- `backend/src/app.module.ts` — 14 modules
- `backend/prisma/schema.prisma` — 13 models

## Tech Stack
- Frontend: React 19, TypeScript 6, Vite 8, TailwindCSS 4, Framer Motion, CometChat
- Backend: NestJS 11, Prisma, PostgreSQL, Redis, Bull, JWT, OneSignal
- Docker Compose for local dev

## Conventions
- React 19 doesn't need `import React from 'react'`
- ESLint: zero errors, warnings ok if documented
- Secrets in .env, never hardcoded
- PWA icons: 192x192 and 512x512 in public/
- Tests: Jest for backend, Vitest for frontend
