## 🚨 ГЛАВНОЕ: ДЕНЕЖНЫЙ КОНТУР НЕ РАБОТАЕТ

**Продавец не может получить деньги.** Это не баг, это отсутствующая логика.

| Проверка | Факт |
|---|---|
| `Transaction` в БД | **0 записей** |
| Заказов в PAID/SHIPPED/COMPLETED | **1167** |
| Инкремент баланса продавцу | **нет в коде** (`payments.service.ts:174-242` — только `referralUserId:219`) |
| Баланс у SELLER | есть (19к, 33к USDT) — но это **сид-данные**, не от платежей |
| `WithdrawalRequest` | **0 записей** |

### Путь денег (что реально происходит)

```
1. Покупатель платит USDT → депозит-адрес paymod
2. Webhook → processSuccessfulPayment()
3. Создаются Transaction-записи: payout_platform / payout_seller / payout_referral
   ⚠️ Это ТОЛЬКО записи в БД. Реальных переводов нет.
4. bonusBalance инкрементится ТОЛЬКО рефералу (:219)
   ❌ Продавцу — НИЧЕГО
5. Продавец идёт в /withdrawals → "Insufficient balance" (bonusBalance=0)
```

**Следствие:** продавец отдаёт товар, деньги остаются на казне платформы, вывести нельзя.

## ВЫВОД

**Интерфейс готов. Продукт — нет.**

UI-слой отполирован (24 UX-проблемы закрыты, тач-таргеты 1122→1, всё замкнуто).
Но **бизнес-логика денег отсутствует**: продавец не получает выручку, эскроу нет,
недоплата проходит, покупатель назначает цену сам, отмена не возвращает деньги.

**Деплоить в прод с реальными деньгами — нельзя.** Это не «баги пофиксим потом»,
это отсутствующий контур: торговля будет работать, а продавцы — не смогут вывести ни копейки.

### Порядок работ

1. **B1+B2** — разделить балансы (trade / referral), начислять продавцу
2. **B5** — эскроу: деньги идут продавцу только после COMPLETED
3. **B7+B8** — сверять сумму депозита, цену брать из товара (не от юзера)
4. **B3+B11** — возвраты при FAILED/CANCELLED
5. **B13** — закрыть IDOR на заказах и юзерах
6. **B14** — Deal.accept должен создавать платёж
7. **N1-N5** — оживить Deal→CLOSED и арбитраж
8. Остальное (🟠🟡)
